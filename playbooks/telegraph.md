# Telegraph 发布（模板）

> 可复用模板，不含账号或真实文章 ID。AI 在用户登录后先读本文件，再决定发布、草稿、复检与报告。

## 目标

用 Telegraph API 快速发一篇极简页面，适合预览、分享和临时长文；不需要账号登录。

## 登录后先确认

1. 不需要扫码；在 Harbor「设置 → 平台账号 → 配置凭据」里 token 可留空，首次发布会自动创建并回写本机 config。
2. 确认 token 可用、作者名正确；失败就停，不重复创建账号。

## 内容适配

- 标题短、直给主题；正文 Markdown 会转 Telegraph Node，代码块和列表保留，复杂 HTML 会丢。
- 没有标签和封面；不要把它当主站，适合“先发出来给人看”的预览稿。
- 主线 `{{profile.mainline}}`，风格 `{{profile.style}}`；正文要有完整上下文，别只放链接。

## 执行

1. 用 `publish_article` 发 `telegraph`；没有草稿，发布即上线。
2. 回读页面 URL：标题、正文首段、代码块可见；图片能加载。
3. 更新用同一 path 原地改，不重复建新页。

## 限制

- 不支持草稿和标签；没有封面。
- 页面公开可访问，别放隐私信息和未公开数据。

## 输出

写明页面 URL、标题、更新/新建状态。明确写“已做完”；未完成写“未完成 + 原因”。

## 硬约束

不放隐私、密钥、未公开文章；图片用稳定外链或 Telegraph 托管。
