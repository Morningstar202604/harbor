# 微信公众号发布（模板）

> 可复用模板，不含账号或真实文章 ID。AI 在用户登录后先读本文件，再决定发布、草稿、复检与报告。

## 目标

用微信公众号官方草稿箱 API 把文章送进后台，默认只进草稿，由用户在公众号后台预览并发表。

## 登录后先确认

1. 这个平台不需要浏览器扫码，在 Harbor「设置 → 平台账号 → 配置凭据」填 `appid` + `secret`。
2. 公众号后台要把 Harbor 所在服务器的公网 IP 加入 IP 白名单，否则 token 接口报 `40164`。
3. 先确认草稿箱能打开；没有权限或 token 失效就停，不要反复取 token。

## 内容适配

- 标题建议 20 字内，正文 HTML 会经过微信白名单过滤，复杂样式会丢，保留段落、代码块、表格即可。
- 正文图片必须换成微信素材库地址；外链图在公众号里不显示。先用 Harbor 的媒体入库/上传能力换链，再发布。
- 主线是 `{{profile.mainline}}`，风格按 `{{profile.style}}`；公众号读者偏好完整教程和结论先行。

## 执行

1. 用 `publish_article` 发 `wechat`，默认 `draft_only=true`，拿到草稿 `media_id`。
2. 打开公众号后台草稿箱，核对标题、正文、图片；由用户预览并发表。
3. 只有认证服务号才可能调用 `freepublish` 直接群发；接口报权限错误时立即降级为“已进草稿，等人工发表”，不伪装成功。

## 限制

- 个人订阅号通常没有 freepublish 权限，默认只能到草稿箱。
- 不支持标签和封面接口；封面在后台手动设置。
- 正文图片不做微信素材上传就会裂图。

## 输出

写明草稿 media_id、草稿箱位置、图片是否已换微信素材链、是否已由用户发表。明确写“已做完”；未完成写“未完成 + 原因”。

## 硬约束

不要把 appid/secret 写进文章或仓库；不要把仓库当图床。
